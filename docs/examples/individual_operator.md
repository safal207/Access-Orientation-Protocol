# Worked Example — Individual Operator

## Context and objective
A solo operator needs to recover consistent deep-work output after two weeks of fragmented execution.

**Objective:** restore a sustainable writing trajectory (5 focused sessions/week) with external validation from published outputs.

## Stage-by-stage walkthrough

### 00 — Resonance (Self)
- Captured internal state: high urgency, low clarity, fear of missed opportunities.
- Declared uncertainty: whether the issue is discipline or poor task framing.
- Output: calibration statement + uncertainty register.

### 01 — Access Point
- Compared candidate anchors:
  1. "Work longer hours"
  2. "Fix task entry quality"
- Selected anchor: improve entry quality (causal leverage higher).
- Output: decision table with rejected alternative rationale.

### 02 — Assembly
- Included only artifacts linked to focus loss:
  - last 10 work sessions,
  - interruption log,
  - output completion times.
- Excluded unrelated productivity advice sources.
- Output: curated assembly manifest.

### 03 — Orientation
- Built relation map: interruptions -> context-switch cost -> perceived urgency -> shallow tasks.
- Prioritized directions:
  1. fixed daily start ritual,
  2. single objective per session,
  3. interruption quarantine window.
- Output: orientation map + ranked direction set.

### 04 — Transition
- Defined trigger to enter operative state: morning calibration note completed + session objective fixed.
- Added rollback condition: if 2 consecutive sessions fail entry criteria, return to stage 03.
- Output: transition checklist.

### 05 — Movement
- Executed 5 sessions with guardrails:
  - no inbox before first focus block,
  - 90-minute protected window.
- Logged deviations (2 interruptions) and corrections (timebox reset).
- Output: movement log + deviation notes.

### 06 — Trajectory
- Observed pattern over 2 weeks:
  - session consistency improved,
  - fewer context switches,
  - improved completion latency.
- Output: trajectory assessment with trend summary.

### 07 — Resonance (World)
- External validation: 2 published outputs, peer feedback indicated clarity improvement.
- Contradiction: one output missed deadline despite better focus.
- Verdict: **partial** (progress validated, schedule reliability still weak).
- Next-cycle input: strengthen estimation discipline.

## Failure branch and recovery path
- Failure branch encountered at stage 05: interruption spike on day 3.
- Recovery: pause movement -> re-enter stage 04 trigger checks -> resume with stricter quarantine window.

## Final verdict
- Task completion: moderate.
- Orientation success: strong but incomplete due to deadline reliability gap.
